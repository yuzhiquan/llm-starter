# 第 5 篇精读｜Transformer 全景：积木怎么搭成大厦

> 原文：llm-05-transformer.md ｜ 前置：第 4 篇 ｜ 核心一句话：Transformer 就是 (Attention + FFN) × N，加上残差这条恒等直通管道和 LayerNorm 这层统一刻度。

## 0. 三句话抓住它

- 一层只有两块：Attention 横向交流，FFN 纵向消化，其余都是胶水。
- GPT-2 的 1.244 亿参数里，FFN 占 45.5%，Embedding 占 31.0%。
- 残差不是技巧而是骨架：它让每层只学"差多少"，不重写全部。

## 1. 这一篇在补哪个洞

第四篇结束在 Attention 的公式上：`softmax(Q·Kᵀ/√d)·V`。它讲清了一个词怎么"看见"别的词，但留下两个明显的缺口。第一，Attention 的输入输出都是 `[n, 768]`，形状没变，它凭什么最终能变成 50,257 个词的概率？第二，如果 Attention 就是全部，GPT-2 为什么要叠 12 层、LLaMA 要叠 32 层，而不是把一层做厚？

本篇回答的具体问题是：**从一个 token ID 进去，到 50,257 个概率出来，中间到底串了哪些模块、每个模块的张量形状怎么对齐、参数都花在谁身上。** 这是"零件"到"整机"的一步，也是全系列唯一一次把全部结构摊平来讲。

补完这一篇，施工图就完整了。它同时给第六篇留了一个悬念：图上这 1.24 亿个数字，初始化时全是随机数，它们靠什么变成有用的值？

## 2. 概念逐层拆

### FFN（Feed-Forward Network，前馈网络）

**是什么**：对每个位置独立做一次 768→3072→768 的两层 MLP，中间夹 GELU。
**为什么需要**：Attention 本质是加权求和，是线性混合；没有 FFN 的非线性，叠多少层都等价于一次线性变换。
**在系统里的位置**：每层后半段，计算环节；输入输出都是 `[序列长度, 768]`，同一层内所有 token 共用一组权重。
**记住这个数**：GPT-2 每层 FFN 有 4,722,432 个参数，正好是 Attention 的 2 倍。

### 残差连接（Residual Connection）

**是什么**：`输出 = 输入 + f(输入)`，把子层输出原样加回输入。
**为什么需要**：没有它，12 层连乘会让梯度指数衰减，浅层收不到有效信号，原始 embedding 也会被逐层覆盖。
**在系统里的位置**：每个子层外层的加法节点，前向与反向都经过，属于结构而非算子。
**记住这个数**：12 层后 `h = Embedding + Δ₁ + … + Δ₁₂`，直通支路的系数恒为 1。

### LayerNorm

**是什么**：对单个 token 的 768 维向量做零均值、单位方差归一化，再乘 γ 加 β。
**为什么需要**：矩阵乘会让某些维度差出几个数量级，Softmax 遇到极端值会把注意力几乎全压在一个位置上。
**在系统里的位置**：每个子层入口（Pre-LN），计算环节，参数量极小但不可省。
**记住这个数**：每层两组、每组 γ 与 β 各 768 个，共 3,072 个参数。

### Pre-LN 布局

**是什么**：`x = x + Attn(LN(x))`，归一化放在子层之前，而不是之后。
**为什么需要**：Post-LN 需要精心 warmup 才能训稳，Pre-LN 的直通主干完全干净，深层更好优化。
**在系统里的位置**：决定残差主干上有没有归一化算子，是结构选择，不是新模块。
**记住这个数**：GPT-2 是 Pre-LN，主干上是一条纯加法链，12 层不插入任何缩放。

### Multi-Head 的拼装

**是什么**：把 768 维切成 12 份 64 维，每份独立做 Attention，拼回 768 再过一次输出投影。
**为什么需要**：单头只能学一种"相关度"，多头让不同头分别盯指代、语法、位置。
**在系统里的位置**：Attention 子层内部，计算环节；Q/K/V 投影是 768×768，切头只是 reshape 与 permute。
**记住这个数**：head_dim = 768 / 12 = 64。

### LM Head 与权重共享

**是什么**：最后一层隐状态乘一个 768×50,257 的矩阵，得到每个 token 的 logit。
**为什么需要**：把"向量空间"翻译回"词表空间"，否则无法做 next-token 分类。
**在系统里的位置**：输出端，计算环节，之后接 Softmax。
**记住这个数**：GPT-2 的 LM Head 与 Token Embedding 共享同一块内存，`data_ptr()` 相等，因此不额外占参数。

### 深度堆叠

**是什么**：把同一套层结构重复 N 次，形状完全不变。
**为什么需要**：单层只能做一次"看上下文 + 消化"，多步推理需要多次改写机会。
**在系统里的位置**：整机主循环，运行时严格串行。
**记住这个数**：GPT-2 12 层、LLaMA 7B 32 层、LLaMA 70B 80 层。

## 3. 手算推演

GPT-2 small 的常量：d = 768，头数 12，FFN 扩展 4 倍即 3072，词表 50,257，最大位置 1,024，层数 12。

**第一步，Attention 子层。**
Q 矩阵 768×768 = 589,824；K、V 同形，各 589,824。
三个合计 3 × 589,824 = 1,769,472。
输出投影 O 也是 768×768 = 589,824。
偏置：Q/K/V/O 各 768 个，4 × 768 = 3,072。
小计 1,769,472 + 589,824 + 3,072 = **2,362,368**。

**第二步，FFN 子层。**
W₁ 是 768×3072 = 2,359,296；W₂ 是 3072×768 = 2,359,296。
偏置 b₁ 有 3,072 个、b₂ 有 768 个，合计 3,840。
小计 2,359,296 × 2 + 3,840 = **4,722,432**。
验算倍数：4,722,432 ÷ 2,362,368 = 2.00，正好两倍。

**第三步，LayerNorm。**
每层两处，每处 γ 与 β 各 768 个：768 × 2 × 2 = **3,072**。

**第四步，单层合计。**
2,362,368 + 4,722,432 + 3,072 = **7,087,872**。
内部占比：Attention 33.33%，FFN 66.63%，LayerNorm 0.04%。

**第五步，12 层。**
7,087,872 × 12 = **85,054,464**。

**第六步，加上两端。**
Token Embedding 50,257 × 768 = 38,597,376。
Position Embedding 1,024 × 768 = 786,432。
最终 LayerNorm 768 × 2 = 1,536。
三项合计 39,385,344。

**第七步，总计。**
85,054,464 + 39,385,344 = **124,439,808**，即 1.244 亿，与原文"约 1.24 亿"一致。

| 部分 | 参数量 | 占比 |
|---|---|---|
| Token Embedding | 38,597,376 | 31.02% |
| Position Embedding | 786,432 | 0.63% |
| Attention（12 层） | 28,348,416 | 22.78% |
| FFN（12 层） | 56,669,184 | 45.54% |
| LayerNorm（12 层 + 最终） | 38,400 | 0.03% |
| 合计 | 124,439,808 | 100% |

验算：38,597,376 + 786,432 + 28,348,416 + 56,669,184 + 38,400 = 124,439,808，分毫不差。

**顺手算一次注意力的计算量。** 序列长 3 时，每个头要算 3×3 的分数矩阵，12 个头共 12 × 9 = 108 个分数；序列长 1,024 时，变成 12 × 1,024² = 12,582,912 个分数。注意这里是**平方**增长，而参数增长是线性的——这就是第四篇说的 n² 复杂度在这张施工图上的具体落点，也是第七篇 KV Cache 要解决的问题。

**一个延伸**：若把 12 层改成 24 层、其余不动，总数是 124,439,808 + 85,054,464 = 209,494,272，约 209M。层数翻倍只让总参数涨 68%，因为 Embedding 被摊薄了——这正是原文说"大模型里 Embedding 只占 2% 左右"的原因。

## 4. 代码逐行

`transformer_anatomy.py`，依赖 transformers 与 torch，首次运行会下载 GPT-2 权重。

```python
total_params = sum(p.numel() for p in model.parameters())
print(f"\n总参数量: {total_params:,} ({total_params / 1e6:.1f}M)")
```
`numel()` 取张量元素个数，遍历所有 Parameter 求和。运行后打印 `124,439,808 (124.4M)`，就是手算第七步的结果。

```python
attn_params = sum(p.numel() for n, p in layer0.named_parameters() if 'attn' in n)
ffn_params = sum(p.numel() for n, p in layer0.named_parameters() if 'mlp' in n)
```
按参数名前缀分类。注意 GPT-2 里 FFN 叫 `mlp` 而不是 `ffn`，用名字过滤比按形状猜安全。分别输出 `2,362,368` 和 `4,722,432`。

```python
residual = hidden
normed = layer.ln_1(hidden)
attn_out = layer.attn(normed)[0]
hidden = residual + attn_out
```
四行就是 Pre-LN 残差块的原文实现：先留原件，再归一化，再算 Attention，最后相加。`[0]` 取注意力输出，元组第二项是注意力权重矩阵。

```python
cos_sim = torch.nn.functional.cosine_similarity(
    original.flatten(), hidden.flatten(), dim=0
).item()
```
每层结束后把当前隐状态与初始 embedding 拉平算余弦相似度。运行后能看到它从 1.000 缓慢下降而非崩塌，这就是直通支路在保信息。

```python
shared = model.transformer.wte.weight.data_ptr() == model.lm_head.weight.data_ptr()
```
`data_ptr()` 返回内存地址。打印 `True` 才说明是同一块内存，而不是两份数值恰好相等的拷贝。

完整运行还能看到 `768 → 50257` 的 logits 形状、Top-5 概率，以及每层范数的百分比变化。

## 6. 类比拆解

| 原文类比 | 它映射到哪一步 | 这个比喻在哪儿会失效 |
|---|---|---|
| 12 个部门依次审阅报告 | 12 层串行前向 | 部门之间可以来回沟通，Transformer 的层严格单向，没有回流 |
| 开会讨论 | Multi-Head Attention | 会上人人平等发言，Attention 里每个位置的话语权由 softmax 权重决定，还被因果掩码截断 |
| 回工位写总结 | FFN | 写总结会引入新信息，FFN 只是对已有向量做固定非线性变换，同层权重对所有 token 相同 |
| 保留原件、在原件上批注 | 残差连接 | 批注人能读懂，Δ 是同维稠密实数，不可解释也不能单独抽取 |
| 统一度量衡 | LayerNorm | 度量衡是全局换算，LayerNorm 是每个 token 各自在自己 768 维内归一化，彼此不通气 |
| 传话游戏 12 轮后失真 | 无残差时的梯度消失 | 传话失真是信息被替换，梯度消失是导数连乘趋零，机制不同但后果相似 |
| 改文章改红字，不重写全稿 | 每层只学残差 | 红字可无限叠加，Δ 的范数会被训练约束，否则会把残差主干淹掉 |

## 7. 五个误区

❌ Transformer 就是 Attention → ✅ 一层里 Attention 只占 33% 参数，FFN 占 67% → 因为 Attention 只有 4 个 d² 矩阵，FFN 有两个 d×4d 矩阵，4 倍扩张直接把参数量翻倍。

❌ 层数越多模型一定越强 → ✅ 深度收益边际递减，还带来训练不稳定与显存线性增长 → 因为每层只多一次"改写机会"，单次能携带多少信息由宽度决定，两者必须配比。

❌ 残差只是为了防梯度消失 → ✅ 它同时改变了参数化方式，让每层只学"差值" → 因为拟合一个接近 0 的修正量，比从零拟合完整表示容易；初始化时 Δ≈0 等价于恒等映射。

❌ LayerNorm 是把数值压到 0~1 → ✅ 它做的是零均值、单位方差，再乘 γ 加 β，输出可正可负、可超 1 → 因为最后一步仿射的 γ、β 是学出来的，模型自己决定要不要还原尺度。

❌ 最后一层输出直接就是答案 → ✅ 还要过最终 LayerNorm、LM Head、Softmax → 因为隐状态是 768 维语义向量，必须投影到 50,257 维词表空间才能变成概率。

## 9. 自测 8 题（含答案要点）

1. 为什么说 Attention 只占一层的一半？
   要点：参数上 2,362,368 对 4,722,432；功能上 Attention 做跨位置混合，FFN 做逐位置非线性，缺一层就不成立。

2. FFN 为什么先升到 4 倍再降回？
   要点：更高维空间里特征更容易线性可分，GELU 在 3,072 维上做筛选；这个扩张也是它成为"知识库"的容量来源。

3. 残差为什么能缓解梯度消失？
   要点：∂(x+f(x))/∂x = I + ∂f/∂x，恒等项保证至少有一条系数为 1 的通路，不会连乘衰减到 0。

4. Pre-LN 与 Post-LN 差在哪？
   要点：归一化位置不同。Pre-LN 主干干净、易训深层；Post-LN 表达力略强但要 warmup。GPT-2 用 Pre-LN。

5. 为什么 LM Head 能和 Embedding 共享权重？
   要点：两者都是 50,257×768，"词→向量"与"向量→词"互为对偶；共享省下 3,859 万参数，还让输入输出共用同一向量空间。

6. 12 层为什么不能换成 1 层做厚？
   要点：一层只有一次"交流+消化"，多步推理需要多次改写；且实验上 bank 的语境区分度从 Layer 0 的 1.000 逐层降到 Layer 12 的 0.614。

7. 【计算】d=768、d_ff=3072 时，FFN 与 Attention 的参数比是多少？
   要点：4,722,432 ÷ 2,362,368 = 2.00，恰好两倍。

8. 【计算】保持其他配置不变，把 GPT-2 层数改成 24，总参数是多少？
   要点：124,439,808 + 85,054,464 = 209,494,272，约 209M，增幅 68%。

## 10. 一页速记

- 一层 = Attention + FFN，各带一个残差，各带一个前置 LayerNorm。
- Attention 混合位置，FFN 消化内容；一个横向，一个纵向。
- 残差让 12 层变成"Embedding + 12 个修正量"的累加。
- LayerNorm 只在每个 token 自己的维度内做，不跨 token。
- 参数分布：FFN 45.5% > Embedding 31.0% > Attention 22.8% > LayerNorm 0.03%。
- 单层 7,087,872 个参数，12 层 85,054,464 个。
- 两端是 Embedding + 位置编码 39,383,808，加最终 LN 1,536，共 39,385,344。
- 总计 124,439,808，与官方 GPT-2 small 完全对齐。
- 深度换推理步数，宽度换单步容量，两者不能互相替代。
- 架构通用，规模才是变量：12 层 / 32 层 / 80 层。

三个关键数字：**7,087,872**（单层参数）、**45.5%**（FFN 占比）、**124,439,808**（总参数）。
