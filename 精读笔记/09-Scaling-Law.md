# 第 9 篇精读｜Scaling Law——为什么"大力出奇迹"有效

> 原文：llm-09-scaling-law.md ｜ 前置：第 8 篇 ｜ 核心一句话：Loss 随参数量、数据量、算力呈幂律下降，log-log 坐标下就是一条可外推的直线。

## 0. 三句话抓住它

- Loss 与 N、D、C 都是幂律关系，log-log 下是一条直线。
- 参数翻 10 倍，Loss 只乘 0.868，不是能力翻 10 倍。
- 算力固定时，参数与数据要按约 1:20 同步放大。

## 1. 这一篇在补哪个洞

第八篇的结尾是一句否定：RoPE 解放了位置编码，但 n² 的计算量和 KV Cache 的线性显存仍是铁律，窗口不是想多大就多大。这留下一个更大的问题——如果堆长度不划算，那堆什么划算？前八篇讲的全是"模型怎么搭、怎么训、怎么推理"，没有一篇回答"该做多大"。

第九篇换了一条轴：不问结构，问规模。GPT-2 是 1.2 亿参数，GPT-4 据估计到了万亿级，中间隔着四个数量级。如果每一档都要真训一遍才能知道效果，研发就是赌博；Scaling Law 把这场赌博变成一条可以外推的曲线。

要提醒一句：这里的 Loss 就是第一篇那个"下一个词的交叉熵"，不是准确率、不是某张榜单的分数。它可测、连续、可微，所以才能拟合；而"会不会写代码"这类能力不可微、还受 prompt 影响，所以只能另做评测。混淆这两层，是后面很多误读的源头。

它补的洞是"规模的可预测性"：不用花几千万美元训 70B，先训几个小模型、量出 Loss、在 log-log 图上画一条线，就能估出 70B 大概在哪。这是整篇最实用的价值，也是后面所有"军备竞赛"叙事的依据。

## 2. 概念逐层拆

### 幂律（Power Law）

- **是什么**：`L(N) ∝ N^(-α)`，参数每乘一个固定倍数，Loss 就乘一个固定倍数。
- **为什么需要**：只有这种"自相似"关系，才能让 1000 万参数上的实验结论迁移到 1000 亿。
- **在系统里的位置**：描述训练结束时的最终 Loss，不描述训练过程，也不描述某一项具体能力。
- **记住这个数**：α 大约在 0.05–0.1 之间（原文口径）。

### log-log 外推

- **是什么**：横轴 log N、纵轴 log L，幂律变成直线，斜率就是 −α。
- **为什么需要**：两点定斜率，第三点做验证，第四点做预测——这是实验设计，不是玄学。
- **在系统里的位置**：训练之前的预算阶段，决定这钱该不该花。
- **记住这个数**：本篇三点算出的 α = 0.0616。

### C ≈ 6ND

- **是什么**：一次训练的总浮点运算量约等于 6 × 参数量 × 训练 token 数。
- **为什么需要**：把"我有多少算力"翻译成"能训多大的模型、喂多少数据"。
- **在系统里的位置**：训练前的资源规划公式，也是 Chinchilla 配比的约束条件。
- **记住这个数**：6 = 前向约 2 + 反向约 4（每个参数每个 token）。

### Chinchilla 20:1

- **是什么**：算力固定时，最优数据量约为参数量的 20 倍。
- **为什么需要**：参数多数据少会"吃不饱"，数据多参数少会"记不住"。
- **在系统里的位置**：决定 N 与 D 怎么分同一笔预算。
- **记住这个数**：7B → 140B token；70B → 1.4T token。

### 涌现（Emergent Ability）

- **是什么**：Loss 平滑下降，但某些任务指标在某个规模后突然抬升。
- **为什么需要**：解释"小模型完全不会、大模型突然会"的体感。
- **在系统里的位置**：能力评估层，不在损失函数里，所以 Scaling Law 本身预测不到。
- **记住这个数**：原文明确承认有争议——换成 log 概率指标，阶跃可能变平滑。

### 过度训练（Over-training）

- **是什么**：故意用远超 20 倍的数据训一个较小模型。
- **为什么需要**：训练成本一次性，推理成本持续；小模型部署后每次都快 10 倍、省 10 倍。
- **在系统里的位置**：产品与成本决策，不是 Loss 最优决策。
- **记住这个数**：LLaMA 7B 用了 1T+ token，约为参数的 140 倍。

## 3. 手算推演

### 3.1 三点定斜率

| 规模 N | Loss L | log₁₀N | log₁₀L |
|---|---|---|---|
| 10M | 3.40 | 7.0000 | 0.5315 |
| 100M | 2.95 | 8.0000 | 0.4698 |
| 1B | 2.56 | 9.0000 | 0.4082 |

取首尾两点，斜率就是幂指数：

```
α = −(log₁₀ 2.56 − log₁₀ 3.40) / (9 − 7)
  = −(0.4082 − 0.5315) / 2
  = 0.1233 / 2
  = 0.0616
```

中间点验证：`L(100M) = 3.40 × 10^(−0.0616) = 3.40 × 0.8677 = 2.950`，与实测 2.95 完全对上。说明这三点确实落在同一条直线上。

### 3.2 外推 10B

从 10M 出发，10B 是 1000 倍，即 3 个数量级：

```
log₁₀ L = 0.5315 − 0.0616 × 3 = 0.3466
L = 10^0.3466 = 2.22
```

换一条路验证：从 1B 再走一格，`2.56 × 0.8677 = 2.221`，一致。

读法：参数从 1B 涨到 10B，10 倍投入只换 0.34 的 Loss。每 10 倍固定乘 0.868、降 13.2%——这就是"收益递减"的精确含义，不是感觉，是乘法。

### 3.3 Chinchilla 配比核算

给定 C = 1×10²² FLOPs，按 `D = 20N` 分配：

```
C = 6ND = 6N × 20N = 120N²
N² = 1e22 / 120 = 8.333×10¹⁹
N  = 9.13×10⁹ ≈ 9.1B
D  = 20N = 1.83×10¹¹ ≈ 183B token
```

回代校验：`6 × 9.13e9 × 1.83e11 = 1.00e22`，预算正好用完。

对照一下"全押大模型"：同样 1e22 全给 70B，只能训 `1e22 / (6 × 7e10) = 2.38e10`，即 23.8B token，只有 0.34 token/参数，离 20 差 59 倍——严重欠训练，Loss 会比 9.1B/183B 的方案差。

再记一条杠杆：在 20:1 约束下 `N ∝ C^0.5`，所以**算力 ×10，参数和数据各 ×√10 = 3.16**，不是其中一项独涨。

口径说明：20:1 是原文给的工程近似，不是物理常数。Chinchilla 自己的拟合指数会让 D/N 随规模轻微漂移，越往大算力走，数据占比通常还要再高一点。所以上面 9.1B / 183B 是"按 20:1 规则算出来的最优"，不是"Chinchilla 论文在这一预算下的精确解"。

## 6. 类比拆解

| 原文类比 | 映射到哪一步 | 这个比喻在哪儿会失效 |
|---|---|---|
| 水从 99°C 到 100°C 沸腾 | 涌现能力 | 水的沸点是固定物理阈值，涌现的"阈值"随指标、prompt、评测集变化，不是常数 |
| 军备竞赛 | 行业算力投入 | 军备有对手和谈判均衡，Scaling 的回报是单边幂律，没有"停战点" |
| 模型"吃不饱" / "记不住" | 欠训练 / 容量不足 | 人吃饱就停，token 喂多了会过拟合、重复数据边际收益趋零，不是线性补 |
| 把赌博变成工程 | 小模型外推大模型 | 只在同架构、同数据分布、同训练配方下成立；换了任何一项，曲线整体平移 |
| 创新是锦上添花，规模是确定回报 | 行业的投入排序 | 创新不是装饰：架构、数据、后训练都能改变斜率或常数项，并非只配"添花" |
| 苦涩的教训：能 scale 的只有算力 | 算力优先 | Sutton 说的是通用方法胜过人工先验，不等于"算力是唯一变量"，数据质量改的是曲线的常数项 |

## 7. 五个误区

- ❌ 参数翻 10 倍，能力翻 10 倍 → ✅ Loss 只乘 0.868 → 因为幂指数只有 0.06 量级，能力更不是线性函数。
- ❌ 20:1 是永远的最优解 → ✅ 只在"训练算力固定"时最优 → 因为推理是持续成本，过度训练常常更划算。
- ❌ Scaling Law 能预测具体任务分数 → ✅ 它只预测 Loss → 因为下游指标与 Loss 不是一一对应，还可能阶跃。
- ❌ 涌现一定是真突变 → ✅ 可能是指标造成的假象 → 因为换成 log 概率后曲线变平滑，学术界仍在争论。
- ❌ 数据可以无限堆 → ✅ 高质量去重 token 有限 → 因为重复数据收益迅速衰减，合成数据还带分布偏差。

## 9. 自测 8 题（含答案要点）

**概念题**

1. 为什么 log-log 下是直线？——幂律取对数后变成线性函数，斜率就是 −α。
2. α = 0.06 的实际含义？——参数量 ×10，Loss ×10^(−0.06) ≈ 0.87。
3. C ≈ 6ND 里的 6 是什么？——前向约 2ND，反向约 4ND，合计 6ND。
4. Chinchilla 的核心结论？——算力固定时 N 与 D 要同步放大，最优约 D = 20N。
5. 为什么会主动选择过度训练？——训练一次性、推理持续，小模型长期总成本更低。
6. 涌现的争议点在哪？——换指标（log 概率替代准确率）后阶跃可能消失，说明"突变"至少部分是度量造成的。

**计算题**

7. 已知 (10M, 3.50) 与 (1B, 2.78)，求 α，并外推 100B 的 Loss。
   `α = log₁₀(3.50/2.78) / 2 = log₁₀(1.2589)/2 = 0.1000/2 = 0.0500`；
   `L(100B) = 2.78 × 100^(−0.05) = 2.78 × 0.7943 = 2.21`。

8. 预算 C = 6×10²³，按 D = 20N 求最优 N、D。
   `N = √(6e23/120) = √(5e21) = 7.07×10¹⁰ ≈ 70.7B`；`D = 20N = 1.41×10¹²`。
   回代 `6 × 7.07e10 × 1.41e12 = 5.98e23` ✓。这正是 Chinchilla 70B / 1.4T 所在的位置。

## 10. 一页速记

- 幂律：log-log 一条直线，斜率 −α。
- α 很小，所以收益递减是常态，不是异常。
- 10× 参数 = 0.868× Loss，降 13.2%。
- C ≈ 6ND，把预算翻译成规模。
- D ≈ 20N，参数和数据要同步。
- 10× 算力 → 3.16× 参数 + 3.16× 数据。
- 小模型外推大模型，是它最大的工程价值。
- 外推只在同架构、同分布、同配方下成立。
- 涌现是 Loss 平滑、指标阶跃，两者不矛盾。
- 数据质量决定曲线的常数项，架构决定斜率。
- 规模是确定回报，创新是锦上添花。

三个关键数字：**0.0616** / **0.868** / **20:1**。
