## 怎么用这套笔记

**第一遍：只看「一页速记」+「0. 三句话」**
16 篇一共不到 5000 字，20 分钟能过完，先建立全局地图。

**第二遍：读正文 + 亲手演算「3. 手算推演」**
这一节是整套笔记的重心。每个机制都落到具体数字上，请拿纸笔跟着算一遍——**看懂和算过是两回事**。遇到算不出来的地方，那正是你的知识缺口。

**第三遍：做「9. 自测 8 题」**
每题都有答案要点，但请先合上笔记自己答。计算题必须真算出数字，不能只写公式。
